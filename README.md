# Robot-Grasping

## Installation
```sh
git clone <git_url>
```

```sh
pip install uv
```

## Run Synthetic Pipeline

```sh
uv run python3 -m scripts.run_grasp_generation_simulation --verbose
```


## Run AruCo-based Pipeline

```sh
uv run python3 -m scripts.run_grasp_generation_aruco --verbose
```
